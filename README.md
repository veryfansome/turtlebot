# turtlebot

A TurtleBot 4 (ROS 2 Jazzy) project: a robot pet that explores the house on its own. See [ROADMAP.md](ROADMAP.md) for the plan, [vm/README.md](vm/README.md) for the Ubuntu VM used to talk to the robot, and [src/pet_explorer](src/pet_explorer/README.md) for the frontier explorer. The repo root is a colcon workspace with ROS 2 packages under `src/`.
